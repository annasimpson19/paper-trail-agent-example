# PAPER TRAIL × OpenClaw

An OpenClaw **tool plugin** (`defineToolPlugin`, TypeBox schemas) with four tools over the shared viem core in `../shared/paperTrail.ts`, plus a skill (`skills/paper-trail-collector/SKILL.md`) that tells the agent when to use them.

| tool | what it does | sends anything? |
|---|---|---|
| `paper_trail_brief` | reads the brief, states the facts | no |
| `paper_trail_verify` | `tokenId` → recomputes the Merkle leaf/root from `/proof` and compares with `passportRoot(collectionId)` on the RUTHVEN registry | no |
| `paper_trail_apply_agent_stage` | signs the operator declaration with the collector wallet (personal_sign), POSTs it, returns the single-use signed-mint permission | no (HTTP only) |
| `paper_trail_mint` | `stage` public/agent, `quantity`, `execute` (**default false = dry run**): verifies featured Passports, applies the operator's rules, re-reads the price from SeaDrop and refuses if it differs from the brief, then sends | only with `execute: true` |

Every price, window, cap and address is read at run time from the brief, the stage endpoint or the chain. An acquisition in the AI Agents stage is recorded publicly as **operator-declared**; the tool results say so. Not an assertion of autonomy, not a recommendation to buy.

## Requirements — read first

- **OpenClaw needs Node ≥ 24.16 (< 25) or ≥ 26.1.** This repository was built and typechecked on Node 20, so `openclaw` itself was **not installed** here and is listed only as a `peerDependency`.
- **The `.d.ts` of `openclaw/plugin-sdk/tool-plugin` was not checked.** `index.ts` follows `docs/plugins/tool-plugins.md` verbatim (`defineToolPlugin`, `configSchema`, `tools: (tool) => [tool({ name, label, description, parameters, outputSchema?, execute(params, config, context) })]`). `types/openclaw-stub.d.ts` is a local stand-in so `npm run typecheck` can check the plugin's own logic without openclaw; delete it once openclaw is installed and let the real types take over. Whether `tool()` also accepts `optional`/`factory`, and whether `uiHints.<field>.sensitive` is the right place to mark the key sensitive, are UNVERIFIED.
- `defineToolPlugin` requires `openclaw >= 2026.5.17`.
- `ports/openclaw` is excluded from the repository's root `tsconfig.json` for the same reason; it has its own `tsconfig.json` (typecheck with the stub) and `tsconfig.build.json` (emit `dist/`).

## Install

```bash
# on a machine with Node 24.16+ and openclaw installed (curl -fsSL https://openclaw.ai/install.sh | bash)
cd ports/openclaw
npm install            # typebox + viem; openclaw is a peer
npm run build          # emits dist/index.js (+ dist/shared/paperTrail.js), which package.json's "openclaw.extensions" points at
openclaw plugins install .          # or: openclaw plugins install --link . to load from this directory
```

The docs say `openclaw.plugin.json` is normally generated by `npm run plugin:build`; the one here is hand-written to the documented shape (id, configSchema, `contracts.tools` listing all four tools, activation) — check it against the generated form once you have openclaw.

Copy `skills/paper-trail-collector/` into your workspace `skills/` directory (or `~/.agents/skills/`) so the agent knows when to use the tools.

## Configure

```json
// openclaw.json
{
  "plugins": {
    "entries": {
      "paper-trail": {
        "enabled": true,
        "config": {
          "privateKey": "0x…",            // collector wallet; marked sensitive; only needed to sign or mint
          "rpcUrl": "https://eth-mainnet.g.alchemy.com/v2/YOUR_KEY"   // optional; defaults to viem's public mainnet RPC
        }
      }
    },
    "allow": ["paper-trail"]
  }
}
```

Restart the gateway. The tools are then callable from any channel. The mint is a dry run until the agent passes `execute: true`, and the skill tells it to do that only on the user's explicit say-so in the conversation.
